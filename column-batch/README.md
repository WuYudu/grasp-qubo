# 整列不可分收益的 QUBO 排序

把抓取收益从"逐件相加"改成"整列清完才计分"，在动作预算下比较四种方法。

## 任务

料箱里有若干列堆叠物体，每列三件，只能从上往下取，动作有预算，搬不完所有列。收益只在一整列被清完时发放，逐件取没有分。于是问题变成：在预算内挑出能完整清完的列。

## 编码

变量分两类：每件一个 x（取不取），每列一个辅助 y（这一列是否清完）。

- 列完成奖励：-B·y + 2B·y - B·y·(该列三个 x 之和)。只有该列三件都取、y 才会带来 -B 的净收益，其余情况 y 留在 0。
- 前置：下面的件要求上面的件先取，写成二次罚项 x_下 - x_下·x_上。
- 预算：λ(Σx - T)^2。

可行解上能量等于负收益，可以直接用能量比较解的质量。

## 四种方法

| 方法 | 做法 |
|---|---|
| 逐件贪心 | 每步取分数最高的可抓件 |
| 按列贪心 | 反复挑剩余总价值最高的列，一次清完 |
| 退火 | 上面的 QUBO 交给模拟退火 |
| 最优 | 预算整除每列数后，取总价值最高的前几列 |

## 结果（18 个实例）

| 方法 | 是否达到最优 |
|---|---|
| 逐件贪心 | 差 0–68.7%，平均约 32% |
| 按列贪心 | 全部达到最优 |
| 退火 | 全部达到最优 |

## 结论

收益不可加时，逐件短视贪心明显吃亏；退火和按列贪心都稳定达到最优。也就是说，这个任务里赢的是"全局方法"，退火是其中一类，并不独占。这个边界要如实写出来。
