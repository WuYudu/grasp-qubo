# 长程台面装配：编排后端的边界

## 项目核心

把"下一步动哪个"这个离散决策写成**可采样的二次型**（QUBO，退火只是它的一种后端），然后用可复现的实验回答一个问题：**这个后端在什么条件下有用、在什么条件下有害。**

不是追求"量子更快"。前面八轮实验（料箱场景）已经把"更快"这条路证伪了：精确解在几百变量上就是最优，退火又慢又差。这里要的是边界——一条能写进论文、能被别人复用的判据。

## 场景为什么换成装配

料箱场景的物理是单调的：搬走一个物体只会放松约束。所以"先规划后执行"没有风险，规划器的差别被机械节拍盖住（实测三种后端逐位相同）。

装配场景换掉三条设定：

- **不可逆**：放进去就固定，放错槽位永久报废，零件一起作废；
- **信息过期**：槽位要求有 55% 的概率是旧信息，且过期的信念仍有 55% 是对的（所以"赌一把"有时是赚的）；
- **成套收益**：某类零件全装完才给 0.90，逐件只有 0.10。

动作 0.7 s，换工具 2 s，重新观测 0.10–0.60 s，总预算 18 s。

## 六个后端，同一份接口

`Backend.plan(state, T, h)` 返回一个动作序列，闭环只执行前 h 个再重新观测。

| 后端 | 策略 |
|---|---|
| `greedy` | 按零件价值从高到低填，不看信息新旧 |
| `greedy_safe` | 只用"当场确认过"的槽位，不赌 |
| `greedy_tool` | 按 `价值 − 换工具代价` 逐步选，顺序参与决策 |
| `risk` | 对过期槽位算期望净收益，负期望不下注 |
| `milp` | 精确整数规划，过期只加线性罚金 |
| `anneal` | 同一问题的 QUBO，模拟退火采样 |

## 结果一：承诺长度是分水岭

（12 件 / 8 槽，过期率 0.55，观测 0.25 s，5 种子）

| h | 保守贪心 | 风险感知 | 整数规划 | 退火 |
|---|---|---|---|---|
| 1 | 0.74 | **0.80** | 0.76 | 0.42 |
| 2 | **0.80** | **0.80** | 0.66 | 0.14 |
| 3 | **0.80** | 0.38 | 0.38 | −0.26 |
| 4 | **0.80** | −0.18 | −0.18 | −0.40 |
| 6 | **0.80** | −0.46 | −0.32 | −0.54 |

三个"聪明"的后端都在 h=2 之后翻负，只有"只用当场确认的信息"的那条平线不动。退火掉得最狠（0.42 → −0.54），因为它的计划最长、承诺最多。

## 结果二：观测变便宜，救不了长计划

固定 h=2 与 h=3，把观测成本从 0.10 拉到 0.60（六倍）：

| 观测成本 | h | 保守贪心 | 风险感知 | 整数规划 |
|---|---|---|---|---|
| 0.10 | 2 | 0.80 | 0.80 | 0.66 |
| 0.25 | 2 | 0.80 | 0.80 | 0.66 |
| 0.60 | 2 | 0.78 | 0.80 | 0.66 |
| 0.10 | 3 | 0.80 | 0.38 | 0.38 |
| 0.60 | 3 | 0.78 | 0.38 | 0.36 |

交点不随观测成本移动。伤害发生在确认之前，把确认做得再快也没用。

## 机制

1. **不可逆把"期望为正"变成"不能下注"。** 线性罚金表达不了毁伤：期望值为正的赌注，只要赌错一次，槽位和零件都不会回来。计划越长，一次赌错覆盖的动作越多。
2. **静态最优 ≠ 可执行的好。** 退火给出的是静态全局最优计划；在不可逆世界里，静态最优恰恰最危险，因为它会把高价值动作全部排进同一份承诺里。

## 边界

- 场景是合成的，状态是轴对齐槽位，不是真实装配的接触动力学；
- 20 步以内的小规模，槽位观测是程序注入而非视觉；
- QUBO 只编码"选哪些（零件,槽位）"，没有位置索引，因此**顺序不在目标函数里**——这是当前最大的缺口，工具切换成本只进了挂钟；
- 所有退火结果都是 CPU 上的模拟退火，没有真机。

## 运行

```
python src/sweep_h.py --plot-only   # 由图复现第一张曲线
python src/sweep_h.py               # 重跑前缀扫描（约 2 分钟）
python src/sweep_obs.py             # 观测成本扫描
```

依赖 numpy、pulp、highspy、dimod、dwave-samplers、Pillow。`world.py` 是场景，`backend.py` 是六个后端，`sim.py` 是闭环，`sweep_h.py` / `sweep_obs.py` 是两个扫描，`figures/fig1_crossover.png` 是曲线。

## 报废判据的稳健性检验

"槽口只认同类零件、放错就报废"是夹具规格约定，不是几何必然。把判据换成长宽几何（`pw <= slot_w`）重跑
四后端 × h=1..4 × 3 种子（`results/calib_rule.csv`，每格"种类判据 / 几何判据"）：

| h | 保守贪心 | 风险感知 | 整数规划 | 退火 |
|---|---|---|---|---|
| 1 | 0.767 / 1.967 | 0.800 / 1.667 | 0.767 / 1.700 | 0.233 / 0.467 |
| 2 | 0.800 / 1.967 | 0.800 / 2.000 | 0.800 / 1.700 | 0.233 / 0.800 |
| 3 | 0.800 / 1.967 | 0.333 / 2.000 | 0.567 / 1.367 | 0.033 / 0.233 |
| 4 | 0.800 / 1.667 | 0.100 / 0.933 | 0.100 / 1.467 | -0.167 / 0.000 |

绝对分数抬高约 1.2、报废率下降，但三条结论不变：承诺长度越过观测边界后优化从加分变扣分；保守贪心始终是最稳的平线；
退火在两种判据下都最差。唯一被改动的排序在 h=2（2.000 vs 1.967，差 0.033），方差盖得住，不作为结论。
物理侧的九格落体矩阵与真计划执行结果见 `physics_check/README.md`。
